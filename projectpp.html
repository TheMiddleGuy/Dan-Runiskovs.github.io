PROJECT 02 / LOW-LEVEL PROGRAMMING

ProjectPP.

A team-built slideshow tool for NES hardware, written in 6502 assembly. My first assembly project challenged me to learn a very different programming model while contributing to a shared codebase.

MY ROLE
Assembly programmer
CONTEXT
Team of 5
TECHNOLOGY
6502 ASSEMBLY / NES
View source ↗

01

My contribution

I integrated sound from scratch, made minor optimisations to the core loop, and added quality-of-life improvements. These were my contributions within a five-person team; the slideshow tool was a collective effort.

02

Learning through unfamiliar hardware

Working in 6502 assembly was my first experience at this level. Understanding the existing program and making useful changes while learning the language was a central challenge of the project.

03

Sound integration

A software issue prevented the available sound libraries from working. After a lengthy attempt to get them running, I wrote the slide beeps from scratch. Simple in principle, but a real challenge for my first encounter with Nintendo hardware. Alongside small quality-of-life additions and minor refactoring, this became my main contribution to the project.
